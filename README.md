# USM – Administración de Sistemas Laboratorio

Laboratorio virtual reproducible para preparar el primer certamen de Administración de Sistemas de la USM.

## Objetivo
Ofrecer un entorno técnico para aprender y verificar conceptos de redes y administración de sistemas.

## Alcance
El alcance previsto incluye teoría y práctica de administración de sistemas, redes virtuales, automatización y troubleshooting.

## Tecnologías y conceptos
El alcance previsto contempla Rocky Linux 10, VMware Workstation, GNS3, VLAN, 802.1Q, Router-on-a-Stick, DHCP, dnsmasq, RADIUS, FreeRADIUS, TLS, routing, diseño jerárquico, Collapsed Core, Spine-Leaf, East-West traffic, QinQ/802.1ad, VXLAN, VTEP, VNI, BGP, EVPN, VRF, multi-tenancy, Fabric-Based Networking, troubleshooting y automatización. Esta lista no declara componentes implementados ni verificaciones realizadas.

## Dependencias y restricciones
Las imágenes y el software Cisco no se almacenan en el repositorio; su uso depende de la licencia y autorización correspondientes. Se prioriza software de código abierto cuando sea posible.

## Estado actual
El laboratorio se encuentra en etapa de definición. No se presentan aquí componentes, topologías, resultados ni verificaciones hasta que estén disponibles y validados.

## Flujo de contribución
1. Trabajar mediante ramas `feat/...`.
2. Revisar los cambios y ejecutar las validaciones disponibles.
3. Abrir un Pull Request para revisión y checks.
4. No hacer push directo a `main`.

La documentación técnica detallada se incorporará en `docs/` cuando exista.
